## Contrôle avant écriture
Vérifier :
1. mécanique centrale ;
2. twist ;
3. pouvoir / anomalie ;
4. conflit relationnel ;
5. type de fin ;
6. ressemblance avec une vidéo déjà publiée ou écrite.
