Démarrer

  1. Ouvre YakFlow dans Chrome ou Edge et colle ton code dans « J’ai déjà un code ».
  2. Mode gratuit Agnes : ajoute ta clé Agnes dans les Réglages, c’est tout.
  3. Images ChatGPT ou animation Grok : installe l’extension Tampermonkey, puis YakFlow Connect (un seul script), et ouvre un onglet chatgpt.com ou grok.com.
  4. Publie depuis ton téléphone : chaque vidéo montée est téléchargée. Installe Google Drive pour ordinateur et synchronise ton dossier Téléchargements (Préférences > Mon ordinateur > Ajouter un dossier) : tout arrive dans l’app Drive du téléphone, rubrique Ordinateurs.
