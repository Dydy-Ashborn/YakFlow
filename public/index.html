Comment ça marche

De zéro à ta première vidéo en 4 étapes

  1. 1

    Télécharge YakFlow

    Dézippe le dossier et double-clique sur « Lancer YakFlow ». Il s’ouvre dans Chrome ou Edge. Python 3 est nécessaire : le lanceur t’aide à l’installer.

  2. 2

    Essaie 24 h gratuitement

    Clique sur « Lancer mon essai gratuit » dans YakFlow et entre ton email : c’est actif tout de suite. Ou colle le code reçu après ton abonnement.

  3. 3

    Écris avec ton IA

    Copie le prompt débutant dans ChatGPT, Claude ou Gemini : il t’aide à trouver ton idée et écrit le fichier à importer.

  4. 4

    Lance et publie

    Importe, clique sur Lancer. Images, clips et montage s’enchaînent, puis la vidéo finie arrive sur ton Drive.

FAQ

Questions fréquentes

Est-ce que je dois payer les IA en plus ?

En mode Gratuit, YakFlow utilise Agnes Image et Agnes Clip : aucun coût de génération, dans la limite des quotas gratuits d’Agnes. Les modes ChatGPT et Grok utilisent tes propres comptes chez ces services.

Comment marche l’essai gratuit ?

Télécharge et lance YakFlow, puis clique sur « Lancer mon essai gratuit » et entre ton email. Tout est débloqué pendant 24 heures, sans carte bancaire. Un essai par ordinateur.

Comment je reçois mon code après l’abonnement ?

Juste après le paiement, tu arrives sur une page qui affiche ton code et le lien de téléchargement. Colle-le dans YakFlow : il se renouvelle tout seul chaque mois tant que ton abonnement est actif.

Est-ce que ça marche sur téléphone ?

Le studio tourne sur ton ordinateur (Mac ou Windows, avec Chrome ou Edge). Avec Google Drive pour ordinateur, chaque vidéo montée arrive automatiquement sur ton téléphone, prête à publier.

Je dois savoir coder ou écrire du JSON ?

Non. Le prompt débutant fait écrire le fichier par ton IA habituelle, à partir de ton idée. Tu n’as plus qu’à l’importer.

Il faut Internet en permanence ?

Il faut Internet pour les IA (Agnes, ChatGPT, Grok). Côté YakFlow, ton code est vérifié une fois à l’activation, puis une fois par mois.

Je change d’ordinateur ?

Ton code fonctionne sur un ordinateur à la fois. Écris-nous avec ton code : on le libère pour ta nouvelle machine.

Comment résilier ?

Avec le lien de gestion présent dans ton reçu Stripe. Tu gardes l’accès jusqu’à la fin du mois payé.
