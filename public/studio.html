Créer un JSON compatible YakFlow
Ton IA écrit le scénario et les prompts. YakFlow orchestre ensuite les images, clips et le montage.






1Fichestype: "fiche"
Personnages et décors de référence. Fabriqués en premier.


2Couverturetype: "couverture"
Image dédiée à la miniature/couverture.


3Scènestype: "scene"
Prompt image + prompt vidéo + durée.




Champs essentiels : racine id, titre, etapes. Chaque étape : id, type, nom, promptImage, joindre. Une scène ajoute promptVideo et secondes (4 à 12). joindre contient les IDs des fiches de référence.


{
  "id": "ma-video-01",
  "titre": "Ma vidéo",
  "etapes": [
    {"id":"fiche-heros","type":"fiche","nom":"Fiche du héros","joindre":[],"promptImage":"..."},
    {"id":"couverture","type":"couverture","nom":"Couverture","joindre":["fiche-heros"],"promptImage":"..."},
    {"id":"scene-1","type":"scene","nom":"Hook","joindre":["fiche-heros"],"promptImage":"...","promptVideo":"...","secondes":7}
  ]
}


À éviter : inventer d’autres valeurs de type, mettre les fiches hors de etapes, renvoyer du Markdown autour du JSON, ou oublier promptImage.
